# Darıca Belediyesi Akıllı Vatandaş Asistanı 🚀

Bu proje, Darıca Belediyesi hizmetleri, nikah ve tesis ücretleri ile idari süreçler hakkında vatandaşlara yardımcı olmak amacıyla geliştirilmiş RAG destekli yapay zeka asistanıdır.

## 🛠️ Teknolojiler
- **Model:** QLoRA Fine-Tuned (3B)
- **Platform:** Hugging Face Spaces & Streamlit
